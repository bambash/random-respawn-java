## [0.1.0] — 2026-05-26

### Added
- Initial release
- Death respawn detection via `time_since_death` scoreboard and `LastDeathLocation` NBT check
- Random coordinate generation using `/random value` (±20,000 blocks on X and Z)
- Teleport to Y=319 via function macro `$teleport @s $(x) 319 $(z)`
- Resistance V applied for 8 seconds to survive the fall
- GeyserMC compatible — fully server-side, works for Bedrock clients transparently
